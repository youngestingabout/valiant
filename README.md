# Valiant web pages

Public pages for the Valiant app, served by GitHub Pages at https://youngestingabout.github.io/valiant/

- `/support/`, `/privacy/`, `/terms/` in English; `/es/support/`, `/es/privacy/`, `/es/terms/` in Spanish.
- Terms and Privacy come from valiant-content's `legal/` folder. Copy the four files into `src/`, run `python3 build.py`, commit.
- The support email appears only on Support.
